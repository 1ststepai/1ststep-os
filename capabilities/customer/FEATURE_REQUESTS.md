# Feature Requests

## Capability
Reusable 1stStep OS module for feature requests.

## Generator contract
When applicable, define:
- user goal
- required inputs
- recommended tools/providers
- free/low-cost alternatives
- expected cost
- permissions/consent
- generated artifacts
- automation level
- quality checks
- risks
- fallback/manual path
- measurable outcome

## Rule
Do not activate this module unless project profile, lifecycle, or user intent makes it relevant.
