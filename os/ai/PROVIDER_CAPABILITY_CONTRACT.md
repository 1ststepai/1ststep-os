# Provider Capability Contract

Each provider/model adapter declares:

- provider ID
- model ID
- endpoint type
- auth method
- context window
- structured output support
- tool/function calling
- streaming
- embeddings
- multimodal input/output
- code execution support
- prompt caching/reuse
- batch support
- rate limits
- latency profile
- price basis
- data retention/privacy notes
- region/residency options
- fine-tuning/customization
- local/self-hosted status
- health status
- last verified
- fallback compatibility

The router must operate on capabilities, not brand names.
