# Local & Self-Hosted Model Support

## Use cases

- privacy-sensitive organizations
- offline development
- predictable cost
- internal enterprise AI
- regulated data
- custom fine-tuned models

## Requirements

1stStep OS should support adapters for local/self-hosted inference where feasible.

Track:
- endpoint
- model identity/version
- hardware/runtime constraints
- context size
- throughput
- latency
- cost estimate
- privacy boundary
- tool/structured-output compatibility
- health
- fallback

## Rule

Do not assume cloud connectivity for every AI workflow.
