# Model Evaluation Registry

## Purpose

Model routing should be based on observed task performance, not provider reputation.

Maintain benchmark/eval results by:
- task type
- model/provider
- cost
- latency
- success rate
- structured-output validity
- hallucination/error rate
- tool reliability
- human-review score where needed

Use evals to determine whether a cheaper/local model is sufficient or whether escalation is required.
