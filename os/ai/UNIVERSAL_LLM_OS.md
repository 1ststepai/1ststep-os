# Universal LLM OS

## Principle

1stStep OS is model/provider agnostic at the canonical layer.

The Project OS, Audit state, findings, evidence, workflows, capability registry, and continuation state must remain portable across AI providers and coding-agent environments.

## Supported classes

- Hosted commercial LLM APIs
- Coding agents
- Chat assistants
- Enterprise model gateways
- Cloud-provider model platforms
- Local/self-hosted models
- Open-weight models
- User-provided/custom model endpoints
- Future providers not known at design time

## Rule

Provider-specific capabilities are adapters, never canonical authority.
