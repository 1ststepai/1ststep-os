# AI Portability

A project should be able to move between AI providers without rewriting its Project OS.

Canonical:
- Project Profile
- Project Genome
- requirements
- decisions
- evidence
- findings
- workflows
- gates
- current state

Adapters:
- Claude Code
- Codex
- Cursor
- Gemini
- Copilot
- Windsurf
- local agents
- custom enterprise agents
- future providers

Provider adapters translate canonical instructions into environment-specific conventions.
