# Universal Model Router

## Router objective

Choose the lowest-cost, lowest-latency model that satisfies required:
- quality
- context
- modality
- tool support
- privacy
- residency
- reliability
- budget

## Routing inputs

- task class
- risk
- expected complexity
- required output schema
- required tools
- context size
- latency target
- privacy level
- project/organization policy
- user subscription/provider availability
- historical eval performance
- cost ceiling

## Routing output

- provider
- model
- context budget
- output budget
- timeout
- retry policy
- fallback chain
- validation method

## Rule

Never assume Claude, OpenAI, Gemini, or any other single vendor is always available.
