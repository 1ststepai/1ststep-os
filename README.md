# 1stStep OS

**Product:** 1stStep OS  
**Parent brand:** 1stStep.ai  
**Public product path:** `https://1ststep.ai/os`  
**Local project path:** `C:\Users\evanp\Documents\Claude\Projects\1stStep OS`  
**Core technology/specification:** Project OS

1stStep OS turns a plain-English idea into a portable, versioned operating system for researching, architecting, building, pricing, branding, launching, growing, and operating a product with AI.

## Core principle

> The Project OS is persistent project memory. AI conversations are disposable execution sessions.

## Start here

1. Read `AGENTS.md` (authority order and vocabulary)
2. Read `PROJECT.md`, `PRODUCT_REQUIREMENTS.md`, `plan/SCOPE.md`
3. Read `ARCHITECTURE.md` and `architecture/decisions/`
4. Read `SECURITY.md`, `EXTERNAL_ACTIONS.md`, `RESEARCH_POLICY.md`
5. Read `DECISIONS.md` and `SCHEMAS.md`
6. Read `state/CURRENT_STATE.md` and `state/NEXT_ACTIONS.md`
7. Start the next cycle from `prompts/NEXT_CYCLE_TEMPLATE.md` and the latest handoff in `handoffs/`.

Checks: `npm install` then `npm test` (includes `npm run check`).

Cycle 1 local demo: `npm run build && npm start`, then open `/os`. Paste an idea, compile, download a markdown ZIP. No model is called.


`FILE_INDEX.md` lists every file.
