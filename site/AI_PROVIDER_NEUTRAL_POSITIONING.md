# /os — Provider-Neutral AI Positioning

## Message

### Use the AI you already have.

1stStep OS doesn't force you into one model or coding agent.

Bring:
- Claude
- Codex
- Gemini
- Cursor
- Copilot
- Windsurf
- local/self-hosted models
- your company's own LLM gateway
- future models

Your Project OS stays the same.

## Supporting line

**Your project belongs to you — not to a model subscription.**

## Visual concept

A central Project OS node connects to multiple model/provider nodes.

Switching providers changes the execution adapter, while the persistent project memory remains unchanged.

## Audit message

If one provider hits a usage limit, the audit can checkpoint and resume later—or fail over to another allowed model—without starting over.
