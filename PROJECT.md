## Product thesis

New AI builders often start coding before they have product requirements, architecture, security boundaries, a business model, pricing rationale, competitor research, launch strategy, distribution, operating procedures, or durable project memory.

For builders who already have a project, the primary commercial entry will be a useful, free, evidence-backed OS Audit. It should explain verified strengths, weaknesses, risks, unknowns, and the next priorities before proposing a Project OS. A healthy project may need little remediation; unnecessary specialist agents must not be recommended. This is the **target model**, not a live capability or a change to the current MVP implementation gate (ADR-021).

As chats grow or agents change, context fragments. The builder re-prompts, contradicts previous decisions, restarts work, and repeatedly re-researches the same questions.

1stStep OS solves this by creating a portable, versioned operating system for the project.

## Product promise

A user describes what they want to build in plain English.

1stStep OS helps them:

1. Clarify the idea.
2. Research the market.
3. Identify customers and competitors.
4. Recommend positioning and pricing.
5. Recommend architecture and stack.
6. Generate the Project OS and specialized agents.
7. Generate bootstrap prompts for AI coding environments.
8. Prepare branding, socials, launch, SEO, content, directories, partnerships, and growth.
9. Track implementation and release readiness.
10. Eventually monitor repository drift, competitors, pricing, distribution channels, and operating health.

## Primary user

## MVP

`Idea / Business Goal → Adaptive Interview → Project Profile → Research → Capability & Module Selection → Recommendations → Project OS Compilation → Preview → Download ZIP → AI Bootstrap Prompt (Start Building)`

This is the **existing scoped foundation loop**. ADR-021 establishes a different primary acquisition direction for existing builders; its free audit, paid spin-up, and specialist offer have no approved implementation milestone or pricing yet. Preserve the idea path rather than replacing it with an audit questionnaire.

Business Owner Mode (a non-developer who wants to automate a business) is part of MVP intake. It produces a ranked automation opportunity map; automations are not executed in MVP. Phase classification: `plan/SCOPE.md`.
