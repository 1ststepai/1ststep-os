# Video Production Pipeline

Brief → audience/goal → script → storyboard → shot list → asset retrieval/generation → screen capture/B-roll → edit → voice → music/SFX → captions → brand package → aspect-ratio variants → QA → approval → publish/export → performance feedback.

Support:
- screen-recorded product demos
- tutorials
- founder videos
- shorts/reels
- ads
- launch trailers
- feature updates
- customer stories
- avatar/talking-head workflows
- dubbing/localization
- clipping long-form to short-form

Prefer deterministic media processing (e.g. trim/merge/transcode/captions/reframe) when AI generation is unnecessary.
