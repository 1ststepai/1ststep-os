# Context Management

## Principle

The model should receive the smallest sufficient context, not the largest available context.

## Context assembler responsibilities

- resolve authority
- retrieve relevant project state
- include exact applicable policies
- select relevant code/files
- enforce token budget
- preserve citations/pointers
- identify missing information
- mark assumptions

## Context artifacts

Maintain lightweight derived indexes:
- repository map
- file purpose index
- architecture index
- decision index
- symbol index
- research index
- open finding index
- current task state

Derived indexes never outrank canonical source files.
