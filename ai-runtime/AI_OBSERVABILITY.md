# AI Observability

## Required dimensions

- provider
- model
- workflow
- project
- user/organization
- token usage
- cost estimate
- latency
- cache hit/miss
- retry count
- fallback
- tool calls
- validation outcome
- eval/quality score where available
- error class

## Dashboards

At minimum:
- cost by feature
- cost by model
- cost by customer tier
- highest-token workflows
- cache/reuse savings
- retry waste
- model routing mix
- quality failures by route
- latency by workflow
