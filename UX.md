# UX Contract

## Beginner-first principle

The user should not need to know:
- framework names
- database choices
- OAuth terminology
- CI/CD
- RLS
- queues
- webhooks
- unit economics jargon

The system translates plain English into expert decisions and explains recommendations.

## Primary journey

1. "What do you want to build, or what do you want to automate in your business?"
2. Adaptive interview
3. "Here is what we understand"
4. Research + recommendations (business owners: ranked automation opportunities)
5. User reviews assumptions/decisions
6. "Generate My OS"
7. Preview generated system
8. Download (connect repository: P1)
9. "Start Building"
10. Next actions (project health scoring: P1)

Information architecture, states, motion and budgets: ADR-013.

## Progressive disclosure

Show beginners:
- recommendation
- reason
- confidence
- decision needed

Hide deep implementation detail behind expandable views.
