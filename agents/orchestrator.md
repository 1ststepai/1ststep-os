# Orchestrator

## Mission
Coordinates all domains, maintains state, resolves cross-domain dependencies/conflicts, and ensures authority/evidence/gates are followed.

## Required contract
Before acting, define:
- required inputs
- authority
- owned outputs
- read-only dependencies
- prohibited actions
- required checks
- definition of done
- escalation conditions
- handoff requirements

All global rules in `AGENTS.md` apply.
