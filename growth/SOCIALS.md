# Social Presence Engine

## Objective
Recommend only platforms that fit the ICP/product.

Potential platforms:
- LinkedIn
- X
- Instagram
- Facebook
- YouTube
- TikTok
- Reddit
- Discord
- GitHub
- Threads
- Bluesky

For selected platforms generate:
- handle candidates
- profile name
- bio
- long description
- profile/banner asset brief
- pinned/launch post draft
- first content set
- content pillars
- cadence
- CTA
- measurement plan

Account creation and posting are external actions governed by `EXTERNAL_ACTIONS.md`.
